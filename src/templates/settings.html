1. Verification Rules

Core runtime delta tolerances, concurrency throttling, and remediation safety gate.

Dry-Run Mode (Safe Observation) When enabled, failed imports are logged to the dashboard as DRY_RUN without deleting or blocklisting files in Radarr/Sonarr. Disable to activate automated remediation.
Max allowed difference between ffprobe duration and TMDB/TVDB runtime (min: 1, default: 15).
Semaphore limit protecting disk I/O during season pack imports (default: 2).
Maximum execution time per ffprobe / OCR subprocess call (default: 120).

2. Tiers & Visual Analysis

Multi-tier audio stream verification, ffmpeg freeze-frame trap detection, and Tesseract OCR title scanning.

Tier 2: Stream & Audio Sanity Check Verify audio track language matches original metadata and channel count matches release tags (5.1 / 7.1).
Tier 3A: Freeze-Frame & Loop Detection Scan sample window with ffmpeg freezedetect to catch padded static-screen fakes.
Reject video if frozen frames exceed this percentage of the sampled window (default: 30%).
Tier 3B: OCR Title Card & Credit Check Extract frames and run Tesseract OCR to detect mockbuster studio credits (e.g. The Asylum).

3. Servarr Integrations

Connect Radarr and Sonarr for metadata enrichment and automated file deletion, blocklisting, and re-search.

Radarr Integration Enable movie verification and Radarr v3 API remediation.
Sonarr Integration Enable episode/season-pack verification and Sonarr v3 API remediation.

Trigger library scans after verified imports and configure paths to ffprobe/ffmpeg binaries.

Jellyfin Library Refresh Trigger a debounced Jellyfin library scan when imports pass verification.
